<h3>Description:</h3>
<p></p>A super basic audio editor for Linux. It's actually a work in progress ;)</p>
<h3>Requirements:</h3>
<ul>
  <li>FLTK, a cross-platform C++ GUI toolkit.</li>
  <li>JACK Audio Connection Kit.</li>
  <li>libsndfile, C library for reading and writing files containing sampled sound.</li>
  <li>libsamplerate, The secret rabbit code, C library for audio sample rate conversion.</li>
</ul>
